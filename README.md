# 🐾 Лапа помощи — сайт приюта для животных

## О проекте

«Лапа помощи» — учебный веб-проект, посвящённый приюту для бездомных животных. Сайт предназначен для знакомства посетителей с животными, которые ищут новый дом, а также для подачи заявок на их пристройство.

## Возможности сайта

- Главная страница с информацией о приюте.
- Каталог собак и кошек.
- Фильтрация животных по категориям.
- Индивидуальные страницы с информацией о каждом животном.
- Форма подачи заявки на пристройство.
- Страница с контактной информацией.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
