# 🐾 Лапа помощи — сайт приюта для животных

## О проекте

«Лапа помощи» — учебный веб-проект, посвящённый приюту для бездомных животных.

Главная цель сайта — помочь животным найти новый дом, познакомить посетителей с питомцами приюта и рассказать о способах оказания помощи.

## Возможности сайта

- Главная страница с информацией о приюте.
- Каталог собак и кошек.
- Фильтрация животных по категориям.
- Индивидуальные страницы питомцев с фотографиями и описаниями.
- Форма для отправки демонстрационной заявки.
- Страница контактов приюта.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Структура проекта

- `index.html` — главная страница.
- `catalog.html` — каталог животных.
- `product.html` — подробная информация о питомцах.
- `order.html` — форма заявки.
- `contacts.html` — контакты.
- `css/style.css` — стили сайта.
- `js/main.js` — JavaScript-скрипты.
- `images/` — изображения животных.
